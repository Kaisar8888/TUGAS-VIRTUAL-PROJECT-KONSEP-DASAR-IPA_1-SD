# TUGAS-VIRTUAL-PROJECT-KONSEP-DASAR-IPA_1-SD
Virtual Laboratory Sederhana IPA SD merupakan media pembelajaran interaktif yang dirancang untuk membantu siswa Sekolah Dasar memahami proses transportasi air pada tumbuhan dan faktor-faktor yang memengaruhi transpirasi. Media ini dilengkapi dengan ilustrasi tumbuhan, pengaturan kondisi lingkungan, simulasi sederhana, tabel hasil pengamatan.
